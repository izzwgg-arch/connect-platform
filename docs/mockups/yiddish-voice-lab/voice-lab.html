Rhythm & cadence marking MOCKUP — not built

    
Select words and/or drag a region on the waveform, then tap what's wrong.

  

  
⚠
Today these become plain-English instruction hints. OpenAI TTS has no per-word prosody control (no SSML, no pause or stress markup), so a mark like "Pause longer here" is folded into the instructions field of a draft config and judged by listening. Future capability word-level prosody control if a provider offers it.
