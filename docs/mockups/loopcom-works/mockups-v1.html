Naming lockup. The Signal Core kit has no vector and "LOOPCOM" is baked pixels, so "Works" is set as a small typographic tag beside the real wordmark — the same way a product line would sit beside a parent brand. If you'd rather have it read "LOOPCOM WORKS" as one piece, that needs a re-render from whoever made the kit.

Loopcom customers use the second button and never type a password — the portal hands them across with a 60-second single-use code. The theme switch is the portal's own segmented control, top-right, pre-login only.

03

Sidebar — expanded and collapsed rail

The portal's sidebar, verbatim: 280px expanded, 72px rail, profile block + company picker at the top, 10px uppercase section labels, 36px links with the 3px accent rail on the active item, icon wells at 30px (36px on the rail). TrimPro's 25 pages keep their order and links; they're grouped the way the portal groups its own. The width does not animate — measured on this machine's GPU, the portal dropped 5.5 frames per toggle when it did.

04

Top bar — search results and account menu

56px fixed bar, three zones: brand (menu button + wordmark + Works tag), global search centered (max 720px, Ctrl K), then dialer, notifications and the account menu on the right. The search result panel and the account menu are shown open at the same time here only so both can be reviewed.
