# PBX Full Brain Export

This is a local read-only PBX knowledge bundle for Cursor.

It may include:
- Asterisk configs
- VitalPBX files
- VitalPBX backups if found
- Asterisk CLI outputs
- service/system info
- backup discovery
- log file index

Use this to understand the real PBX structure before changing Connect.

**Git note:** the companion `pbx-full-brain-*.tar.gz` archive is kept **local only**
(~500MB); it is not committed. The extracted tree + markdown indexes in this folder
are the committed reference snapshot.
